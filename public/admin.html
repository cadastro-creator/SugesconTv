Suas telas

Uma tela é uma TV ou um grupo de TVs que mostram a mesma sequência. Abra o link da tela no navegador da TV (ou no app) e pronto.

Configurar o modo imagem (fotos) — uma vez só

Itens com Modo imagem aparecem na TV como uma foto tirada a cada 15 minutos (segunda a sexta, 7h às 19h) por um robô do GitHub. Para o robô poder enviar as fotos:

  1. Clique em Mostrar chave e depois em Copiar.
  2. No GitHub do projeto: Settings → Secrets and variables → Actions → New repository secret. Nome: FOTOS_TOKEN. Valor: cole a chave.
  3. Se trocar a senha do painel, a chave muda: repita os passos.

Adicionar dashboard

Que links funcionam?
  • Power BI: no relatório, Arquivo → Incorporar relatório → Publicar na Web (público). Copie o link (app.powerbi.com/view?r=…).
  • Looker Studio: Arquivo → Incorporar relatório → marque Ativar incorporação. Compartilhe como “Qualquer pessoa com o link pode ver” e copie o endereço da barra do navegador.
  • Google Planilhas: Arquivo → Compartilhar → Publicar na Web → Publicar. Copie o link gerado.
  • Sites: qualquer endereço https:// que permita exibição dentro de outro site.
